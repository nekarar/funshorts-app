隱私權政策

最後更新：2026 年 10 月 14 日

適用範圍

「怪到發芽 上傳工具」只供頻道擁有者本人使用。

存取的資料

經擁有者授權後，工具會存取擁有者自己的 YouTube 頻道，用於上傳影片、設定影片資訊，以及讀取頻道與影片的觀看統計。

資料的保存與使用

  • 授權憑證只保存在擁有者自己的電腦上。
  • 統計資料只用於擁有者自己檢視頻道成效。
  • 不會出售、分享或提供任何資料給第三方。

撤銷授權

可隨時在 Google 帳戶的「第三方應用程式和服務」頁面撤銷本工具的存取權。

使用 Google API 服務

本工具對 Google API 所取得資訊的使用與傳輸，遵守 Google API 服務使用者資料政策，包括有限使用要求。
