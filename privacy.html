隱私權政策

最後更新：2026 年 10 月 21 日

適用範圍

「怪到發芽 上傳工具」只供頻道擁有者本人使用，不對外開放，也不處理其他使用者的帳號。

存取的資料

經擁有者授權後，工具只存取擁有者自己的帳號：

  • YouTube：上傳影片、設定影片資訊，讀取頻道與影片的觀看統計，以及讀取、回覆自己影片下的留言。
  • Facebook 粉絲專頁：在擁有者管理的粉絲專頁發布 Reels，讀取貼文與影片的成效數據，以及讀取、回覆、隱藏粉絲專頁上的留言。
  • Instagram 專業帳號：在擁有者自己的專業帳號發布 Reels，讀取成效數據，以及讀取、回覆、隱藏自己貼文下的留言。

留言內容只用於回覆與隱藏垃圾訊息，不會用來建立任何人的個人檔案。

資料的保存與使用

  • 授權憑證只保存在擁有者自己的電腦上。
  • 統計資料與留言紀錄只用於擁有者自己經營頻道。
  • 不會出售、分享或提供任何資料給第三方。

撤銷授權

  • Google：可隨時在 Google 帳戶的「第三方應用程式和服務」頁面撤銷本工具的存取權。
  • Facebook 與 Instagram：可隨時在 Facebook「設定和隱私」→「商業整合」移除本工具。

資料刪除

本工具沒有伺服器，所有資料都只在擁有者自己的電腦上。要刪除資料時：

  1. 依上方「撤銷授權」移除本工具在各平台的存取權。
  2. 刪除電腦上本工具的資料夾，以及系統認證管理員中本工具的項目。

完成後，本工具不再保有任何從平台取得的資料。

使用 Google API 服務

本工具對 Google API 所取得資訊的使用與傳輸，遵守 Google API 服務使用者資料政策，包括有限使用要求。
